# Pretii-LightBoard-ImageGen
라이트보드 삽화 모듈의 개조버전입니다.</br>
</br>

기존에는 ComfyUI에서 모든 이미지가 생성되어야 이미지를 채팅창 디스플레이에서 볼 수 있었지만,</br>
개조해서 먼저 생성된 이미지가 차례대로 채팅창 디스플레이에 나타나도록 만들었어.</br>
</br>

## 현재 해결 중인 문제 ##
이미지가 채팅창 사이에 출력될 때 risuai 채팅창이 업데이트되는데 이때 화면이 저절로 스크롤돼버려.</br>
그래서 이미지를 보려면 생성된 이미지가 있는 곳으로 손으로 다시 스크롤 해야해.</br>
채팅창이 업데이트 될 때 스크롤이 튀는 현상은 risuai 자체의 문제라 내가 해결할 수 없어.</br>
